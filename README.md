# Sticker & Converter Bot

Бесплатный Telegram-бот, который:

- делает из картинки статический стикер и добавляет его в ваш стикерпак;
- конвертирует изображения между JPEG, PNG и WEBP;
- собирает несколько изображений в один PDF.

Регистрация не нужна. Файлы хранятся на сервере только на время обработки.

Проект в разработке: сейчас готовы главное меню и команды, обработка изображений появится в следующих версиях.

## Запуск для разработки

Нужен Node.js 24 (версия записана в `.nvmrc`).

1. Создайте отдельного тестового бота у [@BotFather](https://t.me/BotFather). Не используйте токен рабочего бота.
2. Установите зависимости: `npm ci`.
3. Скопируйте `.env.example` в `.env` (в PowerShell: `Copy-Item .env.example .env`) и впишите `BOT_TOKEN`.
4. Запустите: `npm run dev`. Бот получает сообщения через long polling и перезапускается при изменении кода.

Если у бота уже настроен webhook, бот не запустится и назовёт адрес webhook: long polling удалил бы его. Чтобы
переключить бота на long polling, удалите webhook вручную, понимая последствия, или возьмите другого тестового бота.

## Проверки

```
npm run typecheck
npm run lint
npm test
npm run build
```

`npm run lint:fix` исправляет оформление автоматически: табы, фигурные скобки с новой строки, кавычки.
