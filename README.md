# Sticker & Converter Bot

Бесплатный Telegram-бот, который:

- делает из картинки статический стикер и добавляет его в ваш стикерпак;
- конвертирует изображения между JPEG, PNG и WEBP;
- собирает несколько изображений в один PDF.

Регистрация не нужна. Файлы хранятся на сервере только на время обработки.

Проект в разработке: сейчас готовы главное меню и команды, обработка изображений появится в следующих версиях.

## Запуск для разработки

Нужен Node.js 24 (версия записана в `.nvmrc`).

1. Создайте отдельного тестового бота у [@BotFather](https://t.me/BotFather). Не используйте токен рабочего бота.
2. Установите зависимости: `npm ci`.
3. Скопируйте `.env.example` в `.env` (в PowerShell: `Copy-Item .env.example .env`) и впишите `BOT_TOKEN`.
4. Запустите: `npm run dev`. Бот получает сообщения через long polling и перезапускается при изменении кода.

Если у бота уже настроен webhook, бот не запустится и назовёт адрес webhook: long polling удалил бы его. Чтобы
переключить бота на long polling, удалите webhook вручную, понимая последствия, или возьмите другого тестового бота.

### Если api.telegram.org недоступен напрямую

Бот ходит в Telegram сам, а не через браузер: VPN-расширения браузера и системный прокси Windows на него не
действуют. Если `curl.exe -sS -m 15 -o NUL -w "%{http_code}\n" https://api.telegram.org/` не отвечает `302`,
укажите SOCKS-прокси в `.env`:

```
TELEGRAM_PROXY_URL=socks5h://127.0.0.1:40000
```

Это адрес Cloudflare WARP в режиме Local Proxy. Подходит любой SOCKS-прокси (`socks5h`, `socks5`, `socks4a`, `socks4`);
со схемой `socks5h` адрес `api.telegram.org` определяет сам прокси, а не местный DNS. При запуске бот пишет, каким
путём подключается: `via: "direct"` или `via: "socks5h://127.0.0.1:40000"`.

**Ограничение Cloudflare WARP.** В режиме Local Proxy WARP обрывает любой запрос дольше 10 секунд. Поэтому
вместе с WARP задайте короткое ожидание обновлений:

```
POLLING_TIMEOUT_SECONDS=5
```

С этим значением запрос `getUpdates` при отсутствии сообщений завершается через 5 секунд, а не обрывается.
Ограничение касается и будущих операций с файлами: скачивание исходника и отправка результата, которые дольше
10 секунд на медленном канале, через WARP оборвутся. Это ограничение среды разработки, а не бота: сервер вне
России обходится без прокси.

## Проверки

```
npm run typecheck
npm run lint
npm test
npm run build
```

`npm run lint:fix` исправляет оформление автоматически: табы, фигурные скобки с новой строки, кавычки.
